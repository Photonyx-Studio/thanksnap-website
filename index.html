How it works

Three steps, and it runs itself.

01

Add the block once

In Settings → Checkout → Customize checkout, drop the thankSnap block onto the Thank you page. No theme code.

02

Ask one good question

Single choice, multiple choice, text, rating, or yes/no — write your own or start from a template.

03

Answers land on the order

Every response is saved against its order number, exportable as a CSV whenever you want to dig in.
